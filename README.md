## patent-drafting-cn

中国发明专利（以方法类为主）撰写、修改与核查规范 skill，适用于支持 `SKILL.md` 的技能系统。

| 项 | 值 |
| --- | --- |
| 当前版本 | **v3.7** |
| 更新日期 | 2026-11-06 |
| 入口文件 | [SKILL.md](SKILL.md) |
| 规模 | 273 行 / 39,912 字节 |
| 适用范围 | 中国发明专利：权利要求书、说明书、摘要 |

### 覆盖内容

- **速览**：量化指标与禁用清单（条数、字数、标题字数、权项编号、禁用词、名词一致）
- **权利要求**：固定 10 条布局；独权 ≤560 字、特殊情况经说明理由可放宽至 ≤585 字；编号白名单；权项禁数值（区分结构数量与判定数值）；少写常规数据处理；定义后置句下移；判定条件不用括号夹注；系统从权禁用「还包括」；方案名称锁定与权项内容强关联
- **用词规范**：禁用词（含禁「或」）、「较」字使用检查、术语存在性、名词禁简写与同义替换（全篇逐字一致）、「所述」节制、命名分层
- **说明书**：章节顺序、各节写作细则、摘要、公式
- **核查与输出**：量化核查表 +「位置—问题—建议改法」逐项；三处同步核对
- **批注与留痕**：文档内联批注写法；红／蓝／红下划线／黄底纹语义；提交前清除

### 安装

将 `SKILL.md` 放入技能根目录下的同名目录：

```
<dsh-home>/skills/patent-drafting-cn/SKILL.md
```

例如 `~/.dsh/skills/patent-drafting-cn/SKILL.md`。该目录被监视，新增或修改后无需重启即可出现在会话技能目录中。
